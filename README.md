# Homes_API

Homes_API is the backend service for a real estate tracking application, built using .NET 8.0 and connected to a MySQL database. It serves as the API layer for an Angular frontend, providing essential functionality for users to manage and track real estate properties. This application offers a simple solution to track actions, such as conversations, phone calls, and correspondence with sellers and buyers.

## Features
- RESTful API built with .NET 8.0.
- Database interaction with MySQL for reliable data storage.
- Secure user authentication and authorization.
- API endpoints designed to manage users, properties, and related actions.
- Integrated rate-limiting and reCAPTCHA for enhanced security.
- Supports real-time property tracking and user requests.

## Prerequisites
- .NET SDK 8.0 or higher
- MySQL 8.0  or higher Server
- Angular 18.0 or higher frontend (for full functionality)
